# Intern Notes — Mandro

이 폴더는  
3D 프린팅 기반 로봇 의수를 제작하는 중소기업 인턴으로 근무하며  
**내가 어떤 문제를 어떻게 인식했고,  
어떤 기준으로 선택했는지**를 기록하기 위한 공간이다.

이 기록의 목적은 결과물을 나열하는 것이 아니라  
다음과 같은 질문에 답하는 것이다.

- 이 문제를 왜 문제라고 판단했는가?
- 가능한 선택지 중 왜 이 방식을 골랐는가?
- 시간·리소스 제약 속에서 무엇을 포기했는가?
- 다음에 비슷한 상황이 온다면 무엇을 다르게 할 것인가?

<br>

## 📂 기록 구성

### 01_context.md
- 회사/제품/업무 맥락 정리
- 처음 인턴을 시작하며 가졌던 가정
- 역할과 기대치, 제약 조건

### 02_problem-observations.md
- 개발하면서 발견한 문제들
- “처음엔 몰랐는데 나중에 보인 것들”
- 기술적 문제 + 구조적/업무 프로세스 문제 포함

### 03_decision-log.md
- 실제로 내렸던 기술적/구조적 결정들
- 고려했던 다른 선택지
- 선택 기준과 판단 이유

### 04_tradeoffs.md
- 선택으로 얻은 것
- 동시에 감수한 단점
- 시간이 더 있었다면 시도해보고 싶은 대안

### 05_learnings.md
- 기술 외적으로 배운 점
- 혼자 일할 때의 판단 기준
- 이후 인턴/정규직에서 유지하고 싶은 방식


<br>

## ✍️ 기록 원칙

- **완벽하게 정리되지 않아도 기록한다**
- 결과보다 사고 과정을 우선한다
- 회사의 내부 정보나 민감한 내용은 기록하지 않는다
- 나중에 다시 읽었을 때  
  “그때 왜 그렇게 생각했는지” 알 수 있게 쓴다

<br>

이 기록은  
향후 기술 리포트, 커리어 정리 등의 기반 자료로 활용할 예정이다.
