# 04_tradeoffs.md: 선택과 포기

## 1. 교보문고의 전체 텍스트 스캔 방식
* **얻은 것**: 클래스가 없는 척박한 HTML 환경에서도 출판사 정보를 잡아내는 범용성.
* **포기한 것**: 불필요한 텍스트까지 스캔해야 하므로 미세한 연산 비용이 증가했으나, 정확도가 더 중요하다 판단함.

## 2. Yes24의 Bottom-Up 방식 도입
* **얻은 것**: 복잡한 테이블 구조에서도 레이아웃 붕괴 없이 정확하게 타겟 요소를 가리는 안정성.
* **포기한 것**: 사이트별 필터링 메커니즘이 달라져 코드의 일관성이 일부 깨졌으나, 실효성을 위해 이를 허용함.

## 3. 3일간의 MVP 배포 vs Yes24 업데이트
* **판단**: "3대 서점 지원"이라는 타이틀이 제품 신뢰도에 결정적임을 인지, 뒤늦게 밀려오는 귀찮음을 이겨내고 추가 개발을 완수함.
